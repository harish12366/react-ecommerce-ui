# ShopKart - E-Commerce UI

A responsive e-commerce user interface built using React. This project demonstrates reusable components, props, state management, and dynamic product rendering.

## Features

- Responsive navigation bar
- Product banner section
- Dynamic product cards
- Product data managed using a JavaScript array
- Add to Cart and Remove from Cart functionality
- Dynamic cart item count
- Conditional rendering of cart buttons
- Responsive layout for different screen sizes

## Tech Stack

- React
- JavaScript
- HTML5
- CSS3
- Vite

## Concepts Practiced

- React Components
- Props
- useState Hook
- Array map() method
- Array filter() method
- Array some() method
- Event Handling
- Conditional Rendering
- Responsive Design
- CSS Flexbox and Media Queries
